# PR 评论模板

审核者发布审核报告、主 Agent 发布处理报告或仅供参考处置记录时读取。占位符必须换成真实记录；模板本身不是验证证据。发布时正文**不要**包在代码块围栏里——审核报告的末两行必须是裸文本，`scripts/pr_state.py` 才能识别。

## 审核报告

```text
## 第 <N> 轮独立审核
PR：<URL>；base：<分支>；审核者：<本轮子 Agent 标识>（<模型 / 强度 / 新起或续用>）
审核范围：<首轮完整 diff / 上轮SHA..本轮SHA；补充检查范围>
审核覆盖：<调用方、共享模块、数据流、配置及测试覆盖的检查情况>
验证核查：<证据对应 SHA、实际命令/结果、补充验证或未运行原因>

### 发现项
[P<n>] <必须修 / 建议修 / 仅供参考>：<标题>
位置：<文件:行 或具体代码范围>
事实与影响：<可核查事实、触发条件、影响>
建议：<修复方向 / 待裁决问题>

### 旧项核销与裁决
[P<n>] <关闭：修复有效 / 关闭：接受反驳 / 未关闭：原因>
证据：<提交、diff、验证或处理评论链接>
用户延期裁定：<仅在存在用户直接裁定时记录依据与范围>

Reviewed-Head: <完整 40 位 HEAD SHA>
Verdict: <CLEAR 或 BLOCKED（必须修 N 项，建议修 M 项）>
```

- 没有发现时写「发现项：无」，不保留虚构条目；首轮没有旧项时删去「旧项核销与裁决」。
- 编号全 PR 稳定、不复用；级别单独填写。
- 纯文案指摘（PR 标题/正文/注释/说明文档措辞，不改变行为）一律填「仅供参考」；仅供参考不计入 BLOCKED 的项数。提示词/技能文件等行为载体的文字问题按实际影响定级。
- 发布后不要编辑结论评论；需更正时发新的完整报告。

## 逐项处理报告

```text
## 第 <N> 轮处理报告
PR：<URL>；当前完整 HEAD：<SHA>；对应审核评论：<链接>

### 处理状态
| 编号 | 原级别 | 状态 | 修复提交 / 反驳理由与证据 | 独立核销 / 裁决链接 |
|---|---|---|---|---|
| P1 | 必须修 | 已修复，待核销 | <提交 SHA + 改动说明> | 待复审 |
| P2 | 建议修 | 已反驳，待裁决 | <理由 + 证据> | 待复审（新起审核者） |
| P3 | 仅供参考 | 不采纳 | <一句理由> | 无须核销 |

验证：<实际命令、结果、对应 SHA；轻量验证的适用理由>
待复审范围：<上轮SHA..当前SHA；未关闭项；有无 base/范围变化>
复审方式：<续用上轮审核者 / 新起，依据 SKILL.md 2.2>
自检：<强度与结果 / 免自检及理由>
用户裁定：<如有，记录用户原话与范围；不能用主 Agent 判断替代>
```

没有独立核销前一律写「已修复，待核销」；提交反驳不等于关闭。此前未关闭的项全部保留在表中。仅供参考项写「已采纳（提交）」或「不采纳（理由）」即关闭。

## 仅供参考处置记录（CLEAR 后无须复审时）

CLEAR 只带仅供参考项、且不改代码或只经文案豁免落地时，合并前在 PR 发布：

```text
## 仅供参考处置记录
PR：<URL>；适用结论：<审核评论链接>（Reviewed-Head <SHA>）；当前完整 HEAD：<SHA>

| 编号 | 处置 | 说明 |
|---|---|---|
| P1 | 不采纳 | <一句理由> |
| P2 | 已采纳（gh pr edit） | <改了什么> |
| P3 | 已采纳（文案豁免提交 <SHA>） | 核对：仅改点名文件 <文件>；仅注释/说明文字；非行为载体；线性追加；无其他未关闭项 |
```

该记录不含 `Reviewed-Head`/`Verdict` 行，不是审核结论。

## 代发格式（审核者无法发布时）

主 Agent 校验 sha256 后，在审核者原始报告前只加一行，其余原样：

```text
> 代发：审核者 <标识> 原始报告，sha256 <值>，未改动
```

## 发布与恢复

正文写入 UTF-8 临时文件，明确 `--repo` 后用 `gh pr comment --body-file` 发布，避免 shell 对反引号、变量和多行文本二次解释。发布成功、记下 URL 后再删临时文件。超时或网络错误导致结果未知时，先读评论查重，不盲目重发。

## CLI 依据

- [gh pr create](https://cli.github.com/manual/gh_pr_create)：显式指定仓库、base/head 和正文文件。
- [gh pr checks](https://cli.github.com/manual/gh_pr_checks)：`--watch`/`--required`/`--json bucket`；退出码 8 表示 pending。退出码不能替代适用性与 SHA 核实。
- [gh pr merge](https://cli.github.com/manual/gh_pr_merge)：`--match-head-commit` 与合并队列行为。合并队列/自动合并细节见 [merge-queue.md](merge-queue.md)。
