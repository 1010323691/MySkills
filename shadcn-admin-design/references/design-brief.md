# 设计简报模板

在目标项目之外的独立设计目录使用，例如系统临时目录下 `shadcn-admin-design/<任务名>/`。填具体内容，不适用项说明，待定项区分关键阻塞与可接受假设。不要把完整对话复制进项目。

```markdown
# 设计简报

- 工作模式：新设计 / 优化 / 重构
- 目标项目与现有技术栈：
- 业务目标、使用者与关键任务：
- 本次页面与关键操作：
- 不在本次范围内的内容：
- 痛点、必须保留的外观与行为：
- 风格：留白、密度、字体、圆角、阴影、导航
- 内置模板 ID（如选用）与在模板基础上的调整：
- 主色与色板：HEX；背景、文字、状态、图表、侧栏、焦点色
- 明暗主题、语言、设备与无障碍要求：
- 数据字段、来源、权限与关键交互状态：
- 上游参考：来源文件、查阅日期；复制代码时记录实际 ref/commit
- 拟复用组件与适配方式：
- 允许修改的路径、接口与技术边界：
- 假设与待答问题：
- 验收标准：

## 方案版本
- V1：原型与截图路径；页面 / 状态 / 视口；模拟内容说明
- 后续版本：变更原因与对应预览（有时填写）

## 实施确认
- 状态：待确认 / 已批准 / 变更待重新确认
- 批准版本、范围与技术边界：
- 用户确认原话与时间：
- 待定项是否影响实施：

## 交付
- 修改与预览对应关系：
- 实际界面截图 / 预览：
- 运行的检查与结果：
- 已知限制和未完成事项：
```
